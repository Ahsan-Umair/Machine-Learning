## Run a project

Each project retains its own files and, where available, its README. Change into the project folder before running its scripts or notebooks so relative dataset paths work. Install the dependencies listed in that project.

## Large dataset

The fraud-detection project uses Git LFS for `creditcard.csv`. Clone with Git LFS installed and run `git lfs pull` to fetch the dataset.

## Educational use

These are learning projects and experiments. Medical prediction notebooks are not clinically validated tools.

## Organization

Scikit-Learn-Practice-Examples and Deep-Learning are maintained separately and are not included in this collection.
